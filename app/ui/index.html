Vasudha runs entirely on this machine. Nothing you type leaves it. Every number in an answer is calculated in a real Python sandbox — you can open the working and check it.

Set up Vasudha

Vasudha needs its model file once. It is about 2.3 GB and is stored on this machine — after this, the app works with no internet at all.

Settings

Personality

How Vasudha talks Changes tone and detail only. Every persona still computes numbers with Python and shows the working.
Write your own Personas are plain JSON files. Edit one, or add a new file, then restart Vasudha — it will appear here and in the first-run picker.

Engine

Backend Ollama uses your graphics card and is much faster. Built-in needs no install but runs on the CPU.
Model file A .gguf on this machine, used by the built-in backend.
Ollama address Only change this if Ollama runs on another port or machine.

Answers

Temperature Lower is steadier and more repeatable. 0 gives the same answer every time. 0.6
Top-p How much of the probability mass to sample from. 0.9
Reply length limit Tokens per reply. Below about 1500 the model can be cut off mid tool call, which fails the whole answer.
Context window How much conversation the model keeps in view. Larger uses more memory.

Tools

Code timeout Seconds a single Python run may take before it is stopped.
Tool calls per answer Upper limit before Vasudha stops and reports what it has.
Python always runs for numeric questions. On this model, answering without it scored 0 out of 6 on the built-in check; with it, 4 out of 6. That is why there is no switch to turn it off.

Interface

Show working by default Expand the code and output cards without clicking.
Show reasoning by default Expand the model's internal notes on every reply.
Enter sends Off means Enter adds a line and Ctrl+Enter sends.
Reduce motion Turn off transitions and entry animations.
